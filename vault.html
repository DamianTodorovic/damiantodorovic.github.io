Set once, kept

A memory is a node with a type, a weight and a validity, not a text field in a prompt. It is written to one encrypted file on your machine and it stays.

Retrieval is ranking, not quoting

Words and links are scored separately, then fused, and the best-matching memory is lifted. This page ranks words and links in your browser; the product adds trigram vectors and fuses at k=60.

Try the field above. Any node answers.

Provenance is part of the sentence

Person, agent or import, out of a named file, valid since a date you can query against. An answer without provenance is a guess with good grammar.

Hover or focus any node for its proof.

A correction keeps its proof

The superseded memory does not disappear. Its weight drops to a residual, its record stays, and the newer version answers instead. The expired one goes amber, not deleted.

SUPERSEDED and EXPIRED are status levels, not decoration.

The chain reports tampering

Every read and every write is entered, and each entry points to its predecessor. Reach back to change one and the chain breaks where you touched it, and says so.

The five write paths go through the same human gate as the REST path. On a tenant set to review or approve, the door answers pending with an act number and no effect. A person decides whether the memory lands.
